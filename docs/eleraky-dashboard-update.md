# تحديث داشبورد العراقي

النسخة التي فُحصت على Hostinger كانت تعرض ملف Dashboard قديمًا مع أخطاء `D(...) is not a function` داخل خلايا جدول المبيعات، ومفاتيح ترجمة غير مترجمة. التحديث يبني الواجهة الحالية من المصدر مع إضافات تشغيلية فعلية.

## الأقسام المضافة

- ملخص للفترة: قيمة المبيعات المكتملة، عدد الفواتير، متوسط الفاتورة والمتبقي للتحصيل. الرصيد المتبقي يخص فواتير الفترة، ولا يُعرض باعتباره ربحًا أو صافي مديونية العميل.
- اختصارات للفواتير ونقطة البيع وطلبات المتجر والتحويلات والحسابات وتقرير النواقص، حسب صلاحيات الدور والوحدات المفعلة وخطة الاشتراك.
- أقل خمسة أرصدة وصلت إلى حد التنبيه، مع اللون والمقاس والفرع. القائمة تعكس الرصيد الحالي، وتظهر فقط لمن لديه صلاحية `Reports_quantity_alerts`.

المؤشرات تتبع فلتر الفرع والفترة، مع استمرار مقارنة الفروع واتجاه المبيعات والمشتريات وحركة المدفوعات وترتيب الموديلات والمقاسات والألوان والعملاء وآخر المبيعات. لا توجد بيانات أو أرقام مُختلقة عند غياب النشاط.

## الرفع على Hostinger

1. ارفع محتويات ملف التحديث إلى جذر المشروع مع الحفاظ على مسارات المجلدات. ارفع ملفات JavaScript وCSS الجديدة قبل `public/js/.vite/manifest.json`، ثم ارفع ملف manifest أخيرًا. لا تحذف ملفات JavaScript القديمة أثناء التحديث؛ التبويبات المفتوحة قد تحتاجها.
2. تأكد من رفع ملف manifest المخفي داخل `.vite`؛ رفع صفحة Vue وحدها لا يحدّث الموقع.
3. نفّذ من جذر المشروع:

   ```bash
   php artisan migrate --path=database/migrations/2026_11_10_000003_add_catalog_attributes.php --force
   php artisan view:clear
   ```

   الترحيل يضيف أعمدة المقاس واللون والخامة والموسم للنسخ التي لم تطبقه. النسخ التي طبقته مسبقًا ستعرض Nothing to migrate. لا تُشغّل Seeder أو تعِد تثبيت بيانات العرض.
4. أعد تحميل `/next/dashboard`. ملفات البناء لها أسماء جديدة مبنية على المحتوى، فتُحمّل النسخة الجديدة بدل الكاش السابق.

## التحقق

- بناء Vite نجح. جرى فحص الملفات المشار إليها في manifest ضمن حزمة الرفع.
- جرى اختبار الاستعلامات على قاعدة العرض المحلية داخل transaction ثم التراجع عن سجلات الفحص: إجمالي الفترة وعدد الفواتير والمتوسط، وعدم طرح المدفوعات الزائدة من باقي المديونية، وإظهار المخزون السالب، وحصر المخازن والسجلات، وحجب تفاصيل النواقص عن المستخدم بلا صلاحيتها.
- تمت معاينة الواجهة محليًا مع استجابات التطبيق الحقيقية وبيانات العرض، باستخدام جلسة اختبار مؤقتة للقراءة فقط. لم تُغيّر كلمات مرور الحسابات أو صلاحياتها، ولم تُنشر التغييرات على الاستضافة.
